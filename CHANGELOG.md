# Changelog

Notable changes to Charta are documented here. The project follows [Semantic Versioning](https://semver.org/) while treating v0.x releases as public beta software.

## [0.1.0] - 2026-09-09

### Added

- PostgreSQL, Microsoft SQL Server and SQLite connections with OS-keyring password storage.
- Per-connection default schema selection.
- Schema browser, multiple query tabs, cancellable execution and bounded results.
- Dialect-aware highlighting, autocomplete, structural diagnostics, formatting and statement-at-cursor execution.
- Query history, favorites, snippets and result inspectors.
- Cross-platform release archives with checksums, SBOMs and build provenance.

### Security

- Owner-only, atomic local persistence with credential redaction.
- TLS configuration, dependency scanning, CodeQL and pinned GitHub Actions.
